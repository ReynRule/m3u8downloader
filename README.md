# m3u8 downloader (Android)

인앱 브라우저로 사이트에 접속하면 **m3u8 요청을 자동 감지 → 분석/병합 → 목록에 추가**하고,
목록에서 **다중 선택 / 삭제 / 다운로드**할 수 있는 안드로이드 앱입니다.

## 빌드 (GitHub Actions)
1. 이 폴더의 **모든 파일**(숨김 폴더 `.github` 포함)을 GitHub 저장소에 올립니다. (`git push` 권장)
2. 저장소의 **Actions** 탭 → `Build APK` 워크플로가 자동 실행됩니다. (수동: *Run workflow*)
3. 완료 후 실행 결과 페이지 하단 **Artifacts → m3u8-downloader** 에서 `m3u8 downloader.apk` 다운로드.
4. (선택) `v1.0` 같은 태그를 push 하면 Releases 에도 APK가 올라갑니다.

> Gradle Wrapper 없이 워크플로가 Gradle 8.9 를 직접 설치해 빌드합니다.

## 사용법
- **브라우저 탭**: 주소/검색어 입력 후 영상 페이지 접속 → 재생하면 m3u8 감지 → 하단 알림 "목록 보기".
- **다운로드 목록 탭**: 항목 탭=선택(다중), 길게 누름=이름 변경, `선택 다운로드` / `선택 삭제`.
- 저장 위치: `Movies/m3u8 downloader/` (갤러리에서 확인)

## 동작 요약
- WebView 의 모든 네트워크 요청을 감시해 `.m3u8` 감지 (`Detector`)
- master 재생목록이면 최고 화질 variant 자동 선택, 상대경로 → 절대경로로 병합한 재생목록 저장
- 다운로드: 최대 12개 조각 적응형 병렬 · 실패 재시도 · 이어받기 · AES-128 복호화 · 순서대로 병합
- 병합 후 가능하면 MP4 로 무손실 변환(불가 시 .ts 저장), fMP4(HLS CMAF)는 .mp4 로 저장
- **자막 합치기**: 사이트의 자막을 감지해 MP4 안에 **자막 트랙(mov_text)** 으로 넣습니다 (재인코딩 없음, 화질 손실 없음)
  - HLS master 의 `#EXT-X-MEDIA:TYPE=SUBTITLES` 자막(언어/이름 포함), 자막 m3u8(WebVTT 조각)
  - 브라우저가 불러온 `.vtt` / `.srt` / `.ass` 파일 (같은 페이지의 영상에 자동 연결)
  - 여러 언어면 전부 넣고, 기본 자막은 HLS DEFAULT → 한국어 → 첫 번째 순
  - 플레이어(MX Player, VLC 등)에서 자막 트랙 선택으로 켜고 끕니다. 목록 상단 `자막 합치기` 체크로 끌 수 있습니다.
  - 합치기에 실패하면 영상은 그대로 저장하고 자막은 `.srt` 로 따로 저장(기기에 따라 Movies/Download 폴더)

## 제한 사항
- DRM(Widevine/FairPlay/SAMPLE-AES) 영상은 지원하지 않습니다.
- 오디오가 별도 트랙(EXT-X-MEDIA)으로 분리된 스트림은 영상과 합쳐 MP4 로 저장합니다. 단, 소리가 AC-3/E-AC-3 로만 제공되면 합칠 수 없습니다 (AAC 트랙이 있으면 자동으로 AAC 쪽 화질을 고릅니다).
- 자막은 영상 위에 '새겨 넣는(하드코딩)' 방식이 아니라 켜고 끌 수 있는 자막 트랙입니다. 갤러리 기본 플레이어처럼 내장 자막을 못 보여주는 앱에서는 보이지 않을 수 있습니다.
- 자막이 영상 위 HTML 레이어로만 그려지는 사이트(자막 파일을 따로 불러오지 않는 경우)는 감지되지 않습니다.
- 한 페이지에 영상이 여러 개면 그 페이지에서 감지된 자막이 모두 후보로 붙습니다.
- 본인이 저장 권한을 가진 콘텐츠에만 사용하세요.
